## MEDIUM - Purpose-Gate (technique allowed, needs a reason or a change)

**4. "SIAP IMPLEMENTASI" badge matches the AI capsule-badge shape**
`src/components/ResultView.tsx:93-96`
Pill shape (`rounded-full`) + thin border + pulsing dot + tracked micro-text,
the exact combination R-09 calls out as a forbidden default. It's real
status info (not a fake "Beta"/"AI Powered" badge), so the fix is probably
just softening the shape, not removing the badge.
Rule: R-09.

**5. Sparkle icon for "Lainnya" (Other) in the target-user picker**
`src/components/InterviewView.tsx:143`
The catch-all "Other" option uses the Sparkles icon, which has no real
connection to "something else / unspecified." Reads as the generic
AI-magic icon reached for because a 8th icon was needed.
Rule: R-04.

**6. Sparkle icon on the pre-generate notice card**
`src/components/InterviewView.tsx:1423-1424`
Plain informational text ("Semua jawaban akan digabungkan...") wrapped in a
Sparkles icon for no stated reason.
Rule: R-04.

## LOW - Quality Lock / density observation

**7. Uppercase wide-tracking "eyebrow" labels are frequent**
Across `InterviewView.tsx` and `ResultView.tsx`: section tags like
"KELOMPOK X/6 - ...", "- SPESIFIKASI PRODUK", tab/section dividers. Each one
individually fits the established dev-tool/mono identity, but the density
across screens is high enough that it reads as a repeated template tic
rather than a deliberate rhythm. Not a hard violation, just worth a pass to
confirm which ones earn their place and which are filler.
Rule: R-06 (typography without a written reason), density-level only.
